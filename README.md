📘 GitHub do Zero — Cartilha para Iniciantes

📌 Sobre o projeto

Este repositório foi desenvolvido como parte de uma atividade acadêmica do curso de Análise e Desenvolvimento de Sistemas (ADS).

Nosso objetivo é criar uma **cartilha digital educativa e acessível**, destinada a pessoas que desejam aprender a utilizar o GitHub, mesmo sem possuir conhecimentos prévios sobre a plataforma.

O material apresenta explicações simples, exemplos práticos e orientações passo a passo, permitindo que qualquer iniciante compreenda os principais recursos do GitHub.

🎯 Objetivos

- Apresentar o GitHub e suas principais funcionalidades.
- Explicar a diferença entre Git e GitHub.
- Ensinar como criar e configurar uma conta.
- Demonstrar como criar e organizar repositórios.
- Ensinar a adicionar, editar e compartilhar arquivos.
- Explicar o funcionamento de commits e histórico de versões.
- Apresentar formas de colaboração em projetos.
- Incentivar boas práticas de organização e documentação.

📚 Conteúdo da cartilha

A cartilha será organizada nos seguintes capítulos:

**Capítulo 1 — Introdução ao GitHub**

O que é GitHub, para que serve e qual sua importância no desenvolvimento de software.

**Capítulo 2 — Git e GitHub: qual a diferença?**

Conceitos básicos de controle de versões e diferenças entre as duas ferramentas.

**Capítulo 3 — Primeiros passos**

Como criar uma conta, conhecer a interface e configurar o perfil.

**Capítulo 4 — Criando um repositório**

Como criar repositórios públicos e privados e compreender sua estrutura.

**Capítulo 5 — Gerenciando arquivos**

Como adicionar, editar, excluir e organizar arquivos diretamente pelo navegador.

**Capítulo 6 — Commits e histórico de alterações**

O que são commits, como registrar modificações e consultar versões anteriores.

**Capítulo 7 — Colaboração em equipe**

Como convidar colaboradores, utilizar branches e compreender pull requests.

**Capítulo 8 — Atividade prática**

Exercício guiado para colocar em prática os conhecimentos adquiridos.

💻 Metodologia

A cartilha será desenvolvida com linguagem simples, instruções numeradas, exemplos e capturas de tela.

Todas as atividades poderão ser realizadas diretamente pelo navegador, sem necessidade de instalar Git ou utilizar o terminal.
