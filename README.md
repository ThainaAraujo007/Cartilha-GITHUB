# 📌 1. Git: o que é e para que serve?

O Git é uma ferramenta de controle de versões utilizada para acompanhar o desenvolvimento de projetos.

Ele registra alterações realizadas nos arquivos, permitindo consultar o histórico e recuperar versões anteriores.

### Imagine a seguinte situação:

Você está desenvolvendo um site para uma atividade da faculdade.

Na segunda-feira, criou a página inicial. Na terça-feira, adicionou imagens. Na quarta-feira, modificou o layout, mas percebeu que a versão anterior estava melhor.

Com o Git, você pode consultar os registros anteriores e recuperar o conteúdo desejado.

### Principais vantagens

- Acompanhamento das modificações.
- Histórico de versões.
- Recuperação de arquivos.
- Organização do desenvolvimento.
- Possibilidade de trabalhar em diferentes branches.

**Resumindo:** o Git ajuda a controlar a evolução de um projeto.

# 🌐 2. GitHub: onde os projetos se encontram

O GitHub é uma plataforma on-line utilizada para hospedar repositórios Git e facilitar a colaboração entre pessoas.

Ele permite armazenar projetos, compartilhar arquivos, revisar alterações e acompanhar o trabalho realizado pelos integrantes de uma equipe.
